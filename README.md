# Moodleの拡張機能を作ってみよう！

和歌山大学の新入生向け、Chrome拡張機能のハンズオン教材です。スライドを見ながら、少しずつ自分の拡張機能を作ります。

## まずはここから

初めて参加する人は、まず [参加者向けガイド](docs/participant-guide.md) を開いてください。準備から完成までの手順と、スライドに対応したコードの場所を案内しています。

### いまの状況に合わせて選ぶ

- **これから始める**：[参加者向けガイド](docs/participant-guide.md)
- **講座の途中から再開する**：[スライド番号からコードを探す](docs/slide-index.md)
- **うまく動かない**：[困ったときの確認方法](docs/troubleshooting.md)
- **講師として進め方を確認する**：[講師向け進行メモ](docs/facilitator.md)

## 講座の進め方

1. スライドの説明を読み、まず自分でコードを書きます。
2. 対応する `code/` フォルダーのファイルと見比べて、書き間違いを確認します。
3. Chromeで拡張機能を更新し、Moodleのページを再読み込みします。
4. 複数の手順の拡張機能を同時に有効にしないでください。二重に操作されることがあります。

完成コードは答え合わせや復旧用です。最初から完成版を読み込む必要はありません。

## 初回の準備

1. ChromeとVisual Studio Codeを用意します。
2. `wakayama-moodle-auto-login` という作業フォルダーを作り、VS Codeで開きます。
3. スライドの指示に沿って `manifest.json` と `content.js` を作成します。
4. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
5. 「パッケージ化されていない拡張機能を読み込む」から、自分の作業フォルダーを選びます。

## 大学IDとパスワードについて

この教材はログイン画面のボタン操作を学ぶものです。大学IDのパスワードや多要素認証コードを拡張機能に入力・保存することはありません。認証画面が表示されたら、大学の正規画面で本人が操作してください。

実画面では、Moodleトップの「ログイン」から `/2026/login/index_form.html` が開き、大学IDログインはボタンとして表示されることを確認しています。大学IDログイン後の認証や多要素認証までの通し動作は、この教材では確認していません。

## GitHub上のコードを使うとき

GitHubのファイルは見本です。自分の作業フォルダーにコピーして編集し、変更したらChromeで拡張機能を更新してください。ログイン済みページの保存データ、パスワード、認証コードはリポジトリにアップロードしないでください。
