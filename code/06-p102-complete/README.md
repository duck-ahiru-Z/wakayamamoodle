# 第6部：設定連動の完成版

**対応スライド：101〜102**

このフォルダーには、設定画面と自動ログイン処理を連携した完成コードがあります。最初から読み込むものではなく、スライド101〜102まで進んだ後の答え合わせや、作業を復旧するときに使います。

## Chromeに読み込む

1. このフォルダーを自分のPCにダウンロードします。
2. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
3. 「パッケージ化されていない拡張機能を読み込む」を押します。
4. `manifest.json` と `content.js` が入っているこのフォルダーを選びます。
5. 途中の演習版を有効にしている場合は、二重動作を避けるため完成版を使う前に無効にします。

## この完成版の動作

- Moodleトップのログインリンクを探します。
- ログイン画面で「和歌山大学ID」と表示されたボタンを探します。
- 同じタブで同じ段階の操作を繰り返さないようにします。
- ポップアップの設定で自動ログインをON/OFFできます。

実画面では大学IDログインがボタンとして表示されることを確認しています。大学IDを押した後の認証・多要素認証は未確認です。パスワードや認証コードは拡張機能に入力・保存せず、大学の正規画面で本人が操作してください。
