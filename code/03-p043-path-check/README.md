# 第3部：トップページだけクリック

- 対応スライド：**スライド43**（PDF `moodle(1).pdf`、全107ページ）
- このフォルダーはその時点の**完成形**です。ファイル単位ではなく、フォルダーを丸ごとChromeへ読み込みます。
- `chrome://extensions/` → デベロッパーモード →「パッケージ化されていない拡張機能を読み込む」→ **このフォルダー**。
- 既存の演習用拡張機能は重複動作防止のため無効にしてください。
- ここにある内容はスライド掲載コードを基本に整形した教材です。大学の実サイト認証・Microsoft MFAまでの動作は未検証です。
