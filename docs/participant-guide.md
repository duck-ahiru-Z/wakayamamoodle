この資料は、スクリーンのスライドを見ながら **自分のPCで作業する人のための説明書** です。途中で止まったら、まずスライド番号を確認し、対応する完成コードを見てください。2日開催ですが、日ごとにどこまで進むかは固定しません。

## 最初に（スライド1〜5）

**事前に用意**：Chrome、VS Code、和歌山大学Moodleの閲覧環境。ログイン画面を試すときには、大学IDの正規の認証手続きを使います。パスワードや認証コードを拡張機能には書きません。

作業用のフォルダー名は `wakayama-moodle-auto-login`。各章でファイルを **上書きする場合** と **新規作成する場合** があります。

## 第1部（スライド6〜21） 最初の拡張機能

**作業（p9〜10）** コマンドプロンプトで実行します。

```bat
mkdir wakayama-moodle-auto-login
cd wakayama-moodle-auto-login
code .
```

**p12** `manifest.json` を作成。**p16** `content.js` を作成。正しいコードは [p20時点の完成ファイル](../code/01-p020-first-extension/) にあります。

**p18〜19** `chrome://extensions/` にアクセスし、デベロッパーモードをオン。「パッケージ化されていない拡張機能を読み込む」から **自分の作業フォルダー** を選びます。

**p20 合格条件** Moodleを開いて F12 → Console → ページ再読み込み。`Moodle拡張機能が動作しました！` とURLが表示されたら成功。

## 第2部（スライド22〜33） HTMLからボタンを探す

**p26** 未ログインのMoodleで「ログイン」を右クリック →「検証」。Elementsで`<a>`を確認します。

**p27** [ログインリンクを探すコード](../snippets/02-p027-find-login.js) をConsoleで実行。`null` ではなくHTML要素が見えたら成功。

**p29** [クリックするコード](../snippets/02-p029-click-login.js) を続けて実行。ログイン画面に移ったら成功。

**p31** [ボタンなしでもエラーにしないコード](../snippets/02-p031-null-check.js) を確認。

**この部では、作業フォルダーの中身を変更しません。** Consoleの演習です。ファイルを直接書き換えるのは次の第3部です。

## 第3部（スライド34〜46） 自動クリック

**p36** `content.js` を書き換えて、Moodleを開いただけでログインリンクをクリックするようにします。[p36の完成コード](../code/03-p036-auto-click/)

**p39** Ctrl+Sで保存 → Chrome拡張機能の管理画面で更新 → Moodleを再読み込みします。

**p42** Consoleで `window.location.pathname` を見ます。

**p43** トップページ `/2026/` でだけクリックする条件を追加。[p43の完成コード](../code/03-p043-path-check/)

## 第4部（スライド47〜60） 2つ目のログイン画面

**p50** 2つ目のログイン画面で [大学IDログインリンクを探す](../snippets/04-p050-find-oidc.js)。**p51** `.click()` を試します。Microsoft等の認証画面へ進めば成功です（MFAは本人が操作）。

**p53** `else if` を試します。**p55** `content.js` を2画面対応に書き換えます。[p55の完成コード](../code/04-p055-two-buttons/)

**p58 合格条件** トップ → ログイン画面 → 大学ID認証画面へ進む。うまくいかない場合は実際のURLが `/2026/login/index.php` か `/2026/login/index_form.html` かを確認します。

## 第6部（スライド80〜107） 設定画面を作る

**p85** `popup.html` を新規作成。**p90** `manifest.json` に `storage` 権限とポップアップ設定を追加。**p93** `popup.js` を新規作成。ここまでの完成フォルダーは [p93](../code/06-p093-popup-ready/) です。

**p101〜102** `content.js` にオン・オフ判定を追加します。[最終完成コード](../code/06-p102-complete/)

**p105 合格条件** Chrome右上の拡張機能アイコン → 設定画面が開く。OFFでは自動クリックしない。ONに戻して新しいタブでMoodleを開くと動作する。

## 毎回の基本操作

1. VS Codeでファイルを編集し、**Ctrl+S** で保存。
2. `chrome://extensions/` でその拡張機能の**更新**をクリック。
3. Moodle側を再読み込み。ログアウトが必要な課題ではログアウトする。
4. **F12 → Console** でエラーやログを確認。必要なら Preserve logを有効にする。
